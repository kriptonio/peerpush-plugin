# PeerPush

The `peerpush` MCP server gives you read-only tools over PeerPush, a moderated catalog of software products with structured data: pricing model, platforms, use cases, target audiences, alternatives, and community engagement.

Use these tools when the user asks for a software tool or app for a task, alternatives to a product, a comparison of named products, or what is trending, newly launched, or discounted. Do not use them for coding help or for how-to questions about a product the user already uses.

- `peerpush_find_alternative`: alternatives to a named product
- `peerpush_find_product`: a tool for a need described in plain language
- `peerpush_discover`: browse by use case, audience, platform, pricing, or category
- `peerpush_compare`: compare 2 to 5 named products
- `peerpush_product_details`: details of one product
- `peerpush_trending`, `peerpush_new_launches`, `peerpush_deals`: market pulse

Lead with the two or three best matches, use the structured data rather than guessing, and link each product with its `visitUrl` field.
